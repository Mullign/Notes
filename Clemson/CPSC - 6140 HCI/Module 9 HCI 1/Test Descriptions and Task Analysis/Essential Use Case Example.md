​An example of an essential use case for the travel organizer is produced and shown here. ​So here, in order to retrieve visa, the user intention and system responsibilities are ​separately listed here in a tabular form. So the user intention is to find the visa requirements ​and the system responsibility is to request destination and nationality. And if the user ​intention is to supply required information, then the system responsibility is to obtain ​the appropriate visa information and to provide it back to the user. If this user intention ​then is to obtain a copy of the visa information, then the system responsibility is to offer ​information in different formats. And finally, if the user intention is to choose suitable formats, ​then the system responsibility is to provide the information in the chosen format. So you have ​essentially a clear bifurcation of the user intention and the system responsibility. This ​is an example of the essential use case of the travel organizer with regarding to retrieving ​the visa functionality in the travel organizer for the user. Constantine and Lockwood 1999. 

​Basically, they came up with this idea for the essential use case. And here the example is ​provided in the use case based on the visa requirements example, given in the previous ​slides. And it's a very structured narrative, as you can see here consisting of three parts, ​the name that expresses the overall user intention, require visa, step down ​descriptions of the user actions, the system step down descriptions of its responsibility. ​At the time of creating this essential use case, there is no commitment to a particular ​interaction design. So it's a very general definition of the user intention and system ​responsibility that can be accomplished using a multitude of interaction design options. So ​obtain appropriate visa information could mean scanning the passport, accessing a database of ​personal information based on a fingerprint recognition, etc, etc. So you have many ​alternatives for facilitating the interactions for each of these steps.
