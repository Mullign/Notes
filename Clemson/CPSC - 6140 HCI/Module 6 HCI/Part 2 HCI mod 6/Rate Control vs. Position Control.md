Devices can also be rate control versus position control type input devices. The mouse is normally used for position control on the screen and so you can specify the position of any 2D coordinate on the screen using a mouse. The mouse scroll wheel can be used for position control using a rate control scrolling. So the mouse scroll wheel is rate control, but it can be used to specify the position of the cursor by simply controlling the rate of the cursor's movement up and down, for instance. Trackballs typically use position control, so it's an isometric device that allows for position control. And joysticks control both position and also control velocity. So if you push forward or backward, it could control the speed at which you're moving, or it could also directly control the position of a crosshair on the screen as you move it using the joystick in any direction. 

One of the research results that have often been found is that free motion devices, if they are used for rate control, that is, if you use a mouse to control the speed of walking, for example, and then if you use a joystick for position control of a cursor on the screen, they tend to produce poor performance. However, if you flip this arrangement and you use an isotonic control like a mouse to specify the 2D position of a cursor on the screen, and then use an isometric device like a joystick to control the rate or the velocity, the speed of movement of a cursor on the screen, for example, that produces better results. So it's been noted that isotonic devices that are free motion devices without resistance, like a mouse or a 3D controller, like, for instance, a 3D joystick or a 3D controller like the HTC Vive, if they are used for direct position specification of the end effector or a cursor on the screen, they work out much better. And isometric devices like a joystick, a stationary joystick, for example, if they are used for specifying the rate or the speed of motion through the game, they are actually much more appropriate and users get acclimated to them rather easily and find them usable and easy to use.
