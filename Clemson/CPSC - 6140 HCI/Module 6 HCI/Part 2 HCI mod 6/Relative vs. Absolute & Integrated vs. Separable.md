Relative versus absolute movement is fundamentally the difference that is noted between a mouse. The mouse is a relative input device and a tablet is an absolute input device. So that's the difference between the two different types of input devices. Now I'll explain a little bit more. So relative input device essentially takes the relative movements of a mouse on the tabletop surface and basically maps them to movements of a cursor in screen space. So whenever you start the operating system or whenever you start an application on your operating system, the mouse is depicted to be oftentimes in a corner or in the center of the screen and then from there the relative movements of a mouse, either it be perhaps one-to-one or in some other gain factor that maps perhaps one centimeter of movements on the tabletop to perhaps two or one, two or three centimeters of movements in screen space, every movement of the mouse essentially maps to subsequent movements on the screen. So if you lift the mouse and then you go back to the center of your tabletop and move it in the direction that you want to move the cursor on the screen, then basically those additional movements of the mouse are mapped on to the cursor. So in this sense, this is a relative input device. An absolute input device allows you to specify the absolute coordinate where you want the cursor to be. And that can be facilitated via the finger based interaction on a touchscreen surface. So you can directly specify using natural touch where you want the cursor to be and you can specify the cursor's movements by dragging the cursor via touch from one location to another. In other words, you can specify at any given time or continuously the absolute position of a cursor in the 3D space of the virtual environment or in the 2D screen space of a desktop computing environment using touchscreen. So touchscreen based interactions allow you to specify the absolute movements in the screen coordinate or the scene coordinate by using natural touch. 

Whereas the cursor movements are exactly mapped to your finger positions on the screen. So the 2D coordinate of the screen space is used to specify directly the absolute 2D or 3D coordinate of the cursor. Integrated versus separable degrees of freedom has to do with the fact that when you're using this input device, if the degrees of freedom that is the movement directions operate in an integrated fashion, and the mouse essentially is a very good example of integrated degrees of freedom controller, where as you're moving this particular input device, you're actually moving in the integrated degrees of freedom. So as you move the mouse on the tabletop, you're actually moving the cursor in an integrated fashion in both the X and the Y directions. That is the horizontal and vertical directions of the screen space. You cannot move it in isolation only. So as you move in one direction, it also has an effect in the other direction, because the degrees of freedom are integrated for this particular input device. However, you can imagine that if you want to move a cursor on a screen in 2D space, you may have a slider in one direction, perhaps in the horizontal direction, that allows you to specify or move the cursor just in the Y direction or horizontal direction. And you may have a slider in the vertical direction that allows you to specify the movements of the cursor up and down in the vertical direction, but having no change in position in the horizontal direction. So using two sliders, you may be able to, in separable fashion, be able to control the position of a cursor on the screen. So you can think of this as perhaps mimicking the Etch-a-Sketch, which is basically a toy that has the ability to move a cursor on a screen using two sliders on either side, the bottom edge as well as one of the left or the right edges, to be able to move the cursor on the screen and to create art. So you can think of that as essentially similar to the separable degrees of freedom input device that I'm talking about using two different sliders, one horizontal and one vertical.
