So as compared to conventional answering machine that may have many different steps, sometimes perhaps unique as compared to other existing answering machines, when it comes to how to retrieve messages that are on the answering machine, the way that Bishop designed this particular marble answering machine is such that it uses metaphors of picking and placing, for instance, from our day-to-day physical interactions in the world. So when there are messages in the answering machine contingent on how many messages are present, you have that many marbles that are produced by that machine. So in this way, the interaction with this answering marble machine is easy, is intuitive, so even if someone who has had absolutely no experience in using this physical marble answering machine comes in contact with it, they will be able to easily, through experimentation, be able to figure out how to use this machine and be able to interact with it.
