We're going to distinguish between different points here. We have core points, observations with at least minimum number of points, total observations within a radius. We have border points that are not core points, but are within that epsilon of a core point, and we have noise points, which are everything else. So, we have x as a core point here. If we have, I suppose it's four minimum points. y is a border point because it does not have four points within its radius, but it is within radius of a core point, and z is a noise point because it is satisfying neither of these conditions. So, we have density-reasonable and density-connected points. Point A is density-reasonable from point B. 

If there is a set of core points leading from B to A, we can hopscotch each way using only core points. Or if they're density-connected, two points A and B are density-connected if there is a core point C such that both A and B are density-reasonable from C. So, we have a density-based cluster is defined as a group of density-connected points, and we need to decide what our epsilon is. Compute the k-th nearest neighbor distance for each point, plot the distances in a sorted order, and look for a bend in the plot, and use that distance as the choice of epsilon. So, here we have a sort of bend happening somewhere greater than 1000. So, having an epsilon of somewhere in that area makes sense to choose as our first guess at an epsilon value. Always open to tweaking it later on if you see that is appropriate.
