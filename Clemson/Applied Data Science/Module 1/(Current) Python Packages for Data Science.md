These things are always changing so be aware that you may need to update in the future, but here's where we are at now. We have NumPy for large multi-dimensional arrays and matrices. This is a very fast and optimized package to do arithmetic computation. This is a core pillar of data science in Python. So when you're doing big math stuff, NumPy should be where your brain goes. Pandas was built on NumPy. That shows you how efficient NumPy is and used for handling and analyzing structured data. So this is the slicing, the renaming, the categorizing, the grouping. 

Pandas is for working with the data as opposed to computing on the data. Matplotlib is how we make a lot of our graphs, line charts, bar, scatter. We're going to be using that a lot in this class. And it works very well on Jupyter notebooks for interactive plotting. Be aware that as you're showing graphs to people, interactive graphs get huge bonuses and engagement and people just like clicking on things. So it's a good practice to know how to market ourselves as data scientists to the people paying us. Here's just a few other packages, sklearn, pyplot, seaborn.
