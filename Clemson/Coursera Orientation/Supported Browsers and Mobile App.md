You can use Coursera on a computer and mobile devices, like tablets and smartphones.

If you're having problems with Coursera, you might be able to solve them by making sure you're using a supported browser or device, and making sure it's updated.

## Supported browsers

Coursera supports the most recent versions of the following browsers on computers:

- Google Chrome (recommended)
    
- Microsoft Edge
    
- Firefox
    
- Safari
    

If you're using an older browser, updating your browser can help solve problems.

Microsoft announced plans to end support for Internet Explorer starting August 2021, and fully retire the product by June 2022. Coursera support for Internet Explorer ends August 17th 2021. Microsoft Edge browser will continue to be supported, along with Google Chrome as the most compatible browsers for the Coursera platform. 

Please review the requirements for using Coursera on a computer or the mobile app in the [Learner Help Center](https://learner.coursera.help/hc/en-us/articles/209818543-Recommended-browsers-and-devices "Coursera Learner Help Center").

## Coursera mobile app

You can't use the Coursera website on these browsers from a mobile device. To use Coursera on a mobile device, you can [download the Coursera mobile app](https://learner.coursera.help/hc/articles/209818503 "Use the Coursera mobile app Article") on iOS or Android devices. This will allow you to stream lectures or [download material for offline viewing](https://learner.coursera.help/hc/en-us/articles/209818683-Download-videos "Download videos Article") and track your progress on the go. For information on how to download the Coursera mobile app or general troubleshooting, visit the [Learner Help Center](https://learner.coursera.help/hc/en-us/articles/209818503 "Use the Coursera mobile app Article").
