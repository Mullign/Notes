## Setting Up Two-Factor Authentication with DUO

As part of Clemson University’s continuing commitment to protecting its community of research, faculty, staff, and students, the University has implemented two-factor authentication for various campus systems such as Office 365, including email, iROAR, Canvas and more. **You will need to set up two-factor authentication with DUO in order to be able to access important information and tools.** Read about DUO Authentication below, or [click here](https://ccit.clemson.edu/cybersecurity/how-to/duo-authentication/ "How to Set Up DUO Two-Factor Authentication") to visit the University's webpage. To get started with the enrollment process, [click here](https://2fa.app.clemson.edu/ "DUO Enrollment").

## Setting Up Clemson's Virtual Private Network (VPN)

Some Clemson programs and systems require that a computer be located on campus to function properly. To get around this, Clemson has implemented a Virtual Private Network (VPN) for computers that are not on campus. Clemson’s VPN, called CUVPN, functions by routing all of the network traffic on the computer through a secure connection to campus. This makes the computer appear to be on campus for all intents and purposes and is especially useful if a user is in a location with an unsecured network since the CUVPN creates a secure channel. **You must have set up DUO for two-factor authentication before attempting to set up the CUVPN.**

[Click here](https://cuvpn.clemson.edu/+CSCOE+/logon.html#form_title_text "CUVPN Login page") to log into the CUVPN. You will login using your Clemson University username (for example, "jsmith" not "jsmith@clemson.edu") and password. If you need help setting up the CUVPN, you can find more help from the [CCIT Knowledge Base here](https://hdkb.clemson.edu/phpkb/article.php?id=64 "Clemson Computing and Information Technology Knowledge Base").
