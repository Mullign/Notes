# Using your Coursera Labs workspace

You will utilize Coursera Labs throughout the courses you will take to complete the Master of Science in Computer Science program. Coursera Labs will typically use one of three Lab workspaces – Jupyter Notebook, RStudio, or Visual Studio Code (VSCode). This reading will cover how to use the basic features of each of these tools. If your Lab uses a different external tool, you should review your course materials or [course discussion forums](https://learner.coursera.help/hc/articles/208279996-Get-help-with-course-content-in-the-discussion-forums "Get help with course content in the discussion forums") for help.

If you need help troubleshooting issues with your Lab assignments, see: [Solve problems with Coursera Labs.](https://learner.coursera.help/hc/articles/360044758731-Solve-issues-with-Coursera-Labs "Solve problems with Coursera Labs")

## Create new files

See the table below for instructions to create new files in your Lab workspace.

|**Lab workspace**|**Instructions**|
|---|---|
|Jupyter Notebook|Click **New**, then select the file type you’d like to create.|
|RStudio|Select **File** → **New File**.|
|Visual Studio Code (VSCode)|1. Select **File** → **New File**.<br>    <br>2. Give your file a name with the file extension you want (e.g., .css).|

## Download files

To download your files:

1. Go to the **Lab Help** toolbar (top right corner of your workspace).
    
2. Click **Lab Files**.
    
3. To download all your files, click **Download All Files**. To download individual files, check the box next to them and click **Download**.
    

If you don’t see the **Lab Help** toolbar, your course may use a legacy version of the Lab workspace application. Please refer to your course materials for more detailed info about how to use your Lab workspace.

## Open the terminal

See the table below for instructions to open the terminal in your Lab workspace.

## Retake a Lab

If you don’t pass a Lab, you can make adjustments to your code in the Lab workspace, then click **Submit Assignment** once you’re done.

If you’ve already passed a Lab, you can still retake it for practice without affecting your grade. If you’d like to start the Lab over from the beginning, you can see how to [reset your Lab](https://www.coursera.support/s/article/learner-000002188-Using-your-Coursera-Labs-workspace?language=en_US#Reset_Lab "Reset a Lab with Coursera Labs") in the section below.

## Reset a Lab

If you’d like to restart your Lab with the original starter files, you can reset it. Your instructor might tell you to do this if there’s a new version of the starter files for you to use. 

To reset your Lab workspace:

1. In the top right corner, click **Lab Help**.
    
2. From the sidebar, click **Get latest version**.
    

You'll need to rename your Lab file (or move it to a new folder) to get a new copy of the original Lab files. You won't lose any progress when updating the Lab's version.

If you don’t see the **Lab Help** toolbar, your course may use a legacy version of the Lab workspace application. Please refer to your course materials for more detailed info about how to use your Lab workspace.

## Save files

See the table below for instructions to save files in your Lab workspace.

|**Lab workspace**|**Instructions**|
|---|---|
|Jupyter Notebook|Your files will autosave in Jupyter Notebook. <br><br>To manually save, click **File** → **Save and Checkpoint**.|
|RStudio|Your files will autosave in RStudio. <br><br>To manually save, select **File** → **Save**.|
|Visual Studio Code (VSCode)|Your files will autosave in VSCode.<br><br>To manually save, use the following keyboard shortcuts:<br><br>- **Mac**: Command + S<br>    <br>- **PC**: Control + S<br>    <br><br>You can find your saved work in the **/home/coder/project** directory. We recommend keeping your files in this directory so you can continue to access them if you switch course sessions.|

## Unzip files

You can use the terminal to unzip a file in any Lab workspace.

See the table below for instructions to unzip files.

|**Lab workspace**|**Instructions**|
|---|---|
|Jupyter Notebook|After uploading a compressed (.zip) file:<br><br>1. Go to **New** → **Terminal** to open the terminal.<br>    <br>2. Type the following command line to unzip your file: unzip [your-path-to-your-file-and-filename]|
|RStudio|After uploading a compressed (.zip) file:<br><br>1. Go to **Tools** → **Terminal** → **New Terminal** to open the terminal.<br>    <br>2. Type the following command line to unzip your file: unzip [your-path-to-your-file-and-filename]|
|Visual Studio Code (VSCode)|After uploading a compressed (.zip) file:<br><br>1. Go to **Terminal** → **New** to open the terminal.<br>    <br>2. Type the following command line to unzip your file: unzip [your-path-to-your-file-and-filename]|

## Upload files

See the table below for instructions to upload files to your Lab workspace.

|**Lab workspace**|**Instructions**|
|---|---|
|Jupyter Notebook|1. Click the Jupyter logo to open the file tree view.<br>    <br>2. Click **Upload**.<br>    <br>3. Select the file and click **Open**.<br>    <br><br>Your file will be added to your current directory in Jupyter Notebook.|
|RStudio|To upload files in RStudio code:<br><br>1. Open the RStudio file tree, then select **Upload**.<br>    <br>2. Click **Choose File**.<br>    <br>3. Select your file, then click **OK**.<br>    <br><br>Your file will be added to your current directory in RStudio.|
|Visual Studio Code (VSCode)|To upload a file in VSCode, drag the file from your local desktop into your VSCode Lab workspace.<br><br>We recommend keeping your files in the **/home/coder/project** directory so you can continue to access them if you switch course sessions.|

## Use the debugger tool (VSCode)

The debugger tool is only available for VSCode workspaces.

You can learn how to use the VSCode debugger tool on the Visual Studio Code website.

## Use your Lab Sandbox

Some courses have a Lab Sandbox, which is a private workspace where you can practice coding. If your course uses a Lab Sandbox, your instructor should include a link to it in your course materials or assignments. You can launch it by clicking the **Open Lab Sandbox** button.

Your Lab Sandbox will use the same Lab workspace application as your normal assignments. You’ll have access to the Sandbox as long as you’re actively enrolled in the course. 

If you’d like to back up your files, you can [download them](https://www.coursera.support/s/article/learner-000002188-Using-your-Coursera-Labs-workspace?language=en_US#Download_files "Download Files with Coursera Labs") before the course ends.
