The project will be graded based on the following criteria:

## 1. Project Plan (10%)

Completeness and clarity of the project plan (2-3 pages).

- Inclusion of a timeline with milestones and deliverables.
    
- Specificity of tasks outlined for each week.
    

## 2. User Needs Assessment and Data Collection (10%)

User Needs Assessment Report (2-3 pages) with detailed findings and data collection methods.

- Quality and depth of surveys or interviews conducted.
    
- Relevance and completeness of collected data.
    
- Ethical handling and privacy of user information.
    

## 3. AI Tool Setup (10%)

AI Tools Setup Summary (1 page) with reasons for tool selection and setup challenges.

- Appropriateness of chosen AI tools and platforms.
    
- Proper setup of the development environment.
    
- Installation and understanding of necessary libraries.
    

## 4. Data Preprocessing and Exploration (15%)

Data Collection and Preprocessing Report (3-4 pages) with preprocessing steps, tools used, visualizations, and insights.

- Effectiveness in cleaning and preprocessing data.
    
- Depth of data exploration and identification of patterns.
    

## 5. AI Model Development (20%)

AI Model and Performance Report (3-4 pages) with algorithm details, training process, hyperparameters, performance metrics, and challenges.

- Appropriateness of chosen algorithm.
    
- Effectiveness of the built and trained AI model.
    
- Evaluation of model performance using metrics.
    

## 6. User Interface Design and Integration (10%)

UI Design and Integration Report (2 pages) with design process, technologies used, integration steps, and challenges.

- Quality of wireframes and prototypes.
    
- Functionality and usability of the front-end application.
    
- Successful integration of the AI model with the front-end.
    

## 7. Testing and Refinement (10%)

Usability Testing Report (2-3 pages) with testing process, feedback, changes made, and remaining issues.

- Thoroughness of usability testing and feedback collection.
    
- Effectiveness in identifying and fixing bugs.
    
- Refinement of the AI model and user interface based on feedback.
    

## 8. Final Slide Deck and Documentation (10%)

Final Project Report (5-7 pages) covering project overview, methodology, data collection and preprocessing, AI model development, UI design and integration, testing and refinement, final conclusions, and future work.

- Completeness and clarity of the final slide deck (10-12 slides).
    
- Thorough documentation of the development process.
    
- Detailed report on challenges faced and solutions implemented.
    

## 9. Final Project Discussion Posts (5%)

Complete the weekly Final Project Check-Ins by posting to the discussion forum for each week and responding to two of your peers. Review the instructions in the next item for more information.
