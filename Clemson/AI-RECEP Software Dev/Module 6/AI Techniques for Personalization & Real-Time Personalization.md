![[AI Techniques for Personalization & Real-Time Personalization.pdf]]There's a couple of different ways to use AI or personalization. Machine learning, natural language processing, also typically referred to as NLP, collaborative filtering, and finally content-based filtering. With machine learning, you have a system that learns from the user's behavior to make predictions and recommendations. With NLP, you have a system that understands and it responds to user queries and content preferences. With collaborative filtering, your system recommends items based on similar users' behaviors. Finally, the content-based filtering. This system recommends items based on users' past interactions and preferences so this is very unique to that user. 

One of the really cool things about AI is, you can have real-time personalization. You can have a tool that adapts content and recommendations in real-time and this is based on the current users' interactions and previous as well, but also focus on the current ones. You can have dynamic interfaces that change according to user behavior. Some examples include news feeds, product recommendations, and adaptive learning platforms. A good example is TikTok. The algorithm is personalizing each user's experience, which is really cool. Sometimes a bit scary, maybe, but really cool that we can do that.
