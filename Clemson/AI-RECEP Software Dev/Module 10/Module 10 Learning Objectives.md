# Connecting Course Learning Objectives

- **CO 1: Integrate AI Tools in Software Projects:** Learners will be able to integrate various AI tools into software projects, enhancing functionality and user interaction while maintaining a focus on ease of use and accessibility.
    
- **CO 2: Evaluate Ethical Implications of AI in Software Development:** Learners will be able to critically evaluate the ethical implications of using AI in software development, including issues related to privacy, data security, and algorithmic bias.
    
- **CO 3: Apply Principles of Human-Centered Design:** Learners will be able to employ human-centered design principles in the development of software, ensuring that user needs and experiences are at the forefront of the development process.
    
- **CO 4: Create User-Focused AI Solutions:** Learners will be able to design and implement AI-enhanced software solutions that prioritize user needs, preferences, and values, demonstrating a deep comprehension of how AI can enhance user experience.
    
- **CO 5: Conduct Critical Analysis of AI Applications:** Learners will be able to conduct a thorough analysis of existing AI applications in software development, identifying strengths, weaknesses, and areas for improvement in terms of user-centered design.
    
- **CO 6: Present AI Software Development Projects:** Learners will be able to effectively communicate their AI software development projects, articulating the design process, implementation details, and user-centric considerations through clear and engaging presentations.
    
- **CO 7: Identify Roles in Software Development:** Learners will be able to identify the different roles in Software Development and distinguish each role’s contributions to the software development process.
