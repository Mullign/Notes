Let's start with the definition of software engineering. 

Software engineering, also commonly referred to as SE, 

is the process of designing, developing, testing, and maintaining software. 

It requires a combination of technical and analytical skills. 

Core principles of software engineering include developing software, using 

a systematic approach, maintaining code quality through testing and reviews, 

and, finally, continuously improving the software through iterations and feedback. 

The purpose of software engineering is to control complexity, not to create it.
