The word duality, unfortunately, tends to be quite overloaded in computer science. There are several different concepts that we call dualities, relationships between dual pairs of objects, for example. In computational geometry, there are duality relationships between points and lines. We have duality relationships between planar graphs and their so-called dual planar graphs. In this video, I wanted to talk about a very important concept in optimization that we call duality. It's a relationship between pairs of problems that we can exploit in very useful algorithmic ways. So let's spend a few minutes talking about duality and how it is used in optimization. 

So to start out, let's revisit a problem that we've already seen. This is the activity selection problem. We're given as input a set of intervals on the number line, and we would like to choose the largest possible subset of those intervals subject to the constraint that no two of those intervals can overlap with each other. So choose a maximum subset of mutually disjoint intervals. And earlier, when we talked about greedy algorithms, we saw a simple greedy algorithm for solving this problem. So it turns out that this problem has a so-called dual problem, which we could call the disconnection problem. So here, the goal is, again, given a set of intervals, we would like to find a minimum number of cuts that we can make on the number line such that we sever every single interval. 

We have to make sure that every single interval is cut at least once. So why are these problems called duals of each other? Well, it turns out that their objective values satisfy a very useful inequality relationship. So if you take any feasible solution for problem A, the activity selection problem, that is a set of intervals that are all mutually disjoint, then if you look at the number of intervals in that solution, it will be at most the number of cuts you make in any feasible solution for problem B, the disconnection problem. So a feasible solution there is a set of cuts that disconnects every single interval. And so we have basically this weak duality relationship, as it's called. It's an inequality relationship that relates the objective values of these two problems. 

And it's actually pretty easy to see that this inequality relationship has to hold, because as we've noted here in parentheses, if you look at any feasible solution for problem A, that is any set of disjoint intervals, then no matter how you cut the intervals in problem B, every single one of the intervals in that disjoint set needs a separate cut. You can't use one cut to cut two of those intervals, because they're all disjoint from each other. And so the number of cuts that you need is going to be at least as large as the number of intervals in any disjoint set of intervals. So that's why we have this inequality relationship between the two problems. Now it turns out that something stronger happens even with these two problems. If you look at the optimal solutions of the two problems, their objective values actually end up being equal to each other. And you can actually use the weak duality relationship, this inequality relationship, to actually certify optimality for both problems. 

This is actually one of the most useful ways we can use these sorts of duality relationships, because if it so happens that we find a solution for the first problem, i.e. a set of disjoint intervals, and a solution of the second problem, i.e. a set of cuts that disconnects all the intervals, and those two solutions are equal, so the same number of intervals as cuts, then it must be the case that both of those solutions are optimal for their respective problems. Otherwise, if they weren't optimal, then maybe you had a solution that involved more intervals or less cuts, that would violate this inequality relationship. And so this is a really useful concept that follows from these inequality relationships. You can actually certify optimality if you happen to be able to demonstrate a solution of your dual problem that matches the solution of your original problem in terms of objective value. Let's actually take a look at how we can use this fact to actually prove optimality of greedy algorithms for those two problems. So if we look at a simple example of a set of intervals, I've actually got the same example shown twice, because I'm going to show how to solve it with greedy algorithms for both problems. So in the activity selection problem, remember that the greedy algorithm that we used always selected the activity that ended earliest.

Well, kind of along the same lines of reasoning that we talked about before, since we know that a solution for the cut problem is always bigger than the objective value of a solution for the activity selection problem, we can kind of look at the gap between any two such solutions. So take a solution for the cut problem and a solution for the interval problem and look at the gap between the objective values of those two solutions. That basically tells you a kind of a measure of distance to optimality for each of those two solutions. Remember, if the solutions meet, if there's no gap, then they're both optimal. But if the solutions are, say, seven apart from each other, that means that each solution is at most seven away from optimal, because you know you can't cross over the solution of your dual problem. And so this is an incredibly common use of duality in optimization. You can get a bound on how close to optimal you are.
