# Prerequisites 
Prior coursework in discrete math, linear algebra, probability algorithms, and data structure helpful, but not required
- We'll cover things from ground up, but if your background is light in some areas you may need occasionally look up basics topics as needed. 
Assignments will involve implementation (in C++, Python, or Java), so you should be ok at writing code in one of these languages.
Enthusiasm, willingness to challenge yourself, resilience.
