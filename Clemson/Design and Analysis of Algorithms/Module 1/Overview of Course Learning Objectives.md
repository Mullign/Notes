You will see learning objectives for each module in this course, but there are also course-level objectives that guide the learning and assessments taking place. Below are the course-level objectives for **Design and Analysis of Algorithms**. The following tables illustrate how these objectives align with the module-level learning objectives. As a learner, you can achieve these goals by engaging in the activities and completing the assessments aligned with each objective.

You can revisit this overview at any time, but you will also see a table showing how each module connects with the course-level learning objectives after viewing the Module Overview video for each module. (For example, after watching "Module 1 Overview," you'll see the reading, "Connecting Course Learning Objectives" with the table for Module 1 that you see here).

# Course-Level Objectives:

- **CO 1:** Explain the fundamentals of a wide range of algorithm design and analysis technique.
    
- **CO 2:** Identify and replicate standard algorithms for standard problems.
    
- **CO 3:** Implement algorithmic ideas in code.
