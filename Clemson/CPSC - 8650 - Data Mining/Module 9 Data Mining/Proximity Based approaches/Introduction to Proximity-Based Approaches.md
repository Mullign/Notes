​Now we study the proximity-based approaches for outline detection, including distance-based ​and density-based outline detection. ​Okay, so an object far from others can be regarded as outline. ​That's our main idea with the proximity-based approaches, okay? ​There are two types of proximity-based outline detection methods, one based on the distance ​we call the distance-based method. ​So an object is considered as outliner if its neighborhood does not have enough other ​points. ​So here is a key that we want to find the neighborhood. ​So the neighborhood has a short distance, and then also the neighborhood should not ​have enough number of points within that neighborhood. 

​And the density-based method is an object is an outliner if its density is relatively ​much lower than its neighbors. ​So we need to find a relative density of an object.
