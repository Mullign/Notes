So we'll continue with Module 3, Data Reduction, and then followed with Dimensional Reduction. What is a data reduction? Data reduction is to obtain and reduce the representation of the original data set so that the data are much smaller in volume but produce almost the same analytic result. Why do we need to reduce the data? Because a database or data warehouse may store terabytes of data. And complex analysis may take a very long time to run on the complete data set. So we need to reduce the data set. 

The method for data reduction we also call as a data size reduction, or sometimes we call that the numerosity reduction, and include regression and logarithmic method models, histograms, clustering, and sampling, and data cube aggregation, and data compression. So we will focus on the data reduction. The first method is called parametric or nonparametric method. So the first method is called parametric method, such as regression. So we want to reduce the data volume by the alternative or smaller form of data. For parametric method, we actually try to reduce the data with certain model. So we find some model that it will fit all the data into that model. 

And then we estimate the model parameters. Then we only store the model parameters, OK? And discard all the data. Of course, probably, if you have R-liners, then you can keep those R-liners for data analysis. And for example, nonlinear model, we can obtain values at a point in the MD space as the product on the approximate marginal subspace. By doing that, you just use the model parameter to represent the original data. We already studied some nonparametric methods, OK? 

In that case, we are not going to use any model or make any assumption on the data distribution. What you do is we can use histograms, clustering, and the sampling approach to actually partition the data or reduce the data size. For example, we do the histogram. So we bin. It is like a binning, OK? You put the data into the binning and then give the values there, OK? It's kind of data transformation, transform from the original data value into the frequency, OK, to represent into the bin values there. 

Then we can use the clustering. And then you get more clusters, OK? And then you can do a sampling. You can do like a stratified sampling. So those are the major nonparametric methods.
