​The next type of application in the sentiment data application is the truth discovery and ​the misinformation identification. ​So the truth discovery, the goal of the truth discovery is to assess and choose the actual ​true value for a data item when different sources provide conflict information on it. ​So there are different types of truth discovery. ​The single truth discovery, which only one true value is allowed for a data item. ​You may have a multiple truth discovery where multiple true values are allowed for data ​items. ​There are several challenges for this truth discovery. ​First is the source trustworthiness, and then the second is the claim reliability. 

​Another challenge is that there is a limited amount of labeled data sources. ​So the primary techniques that are used in truth discovery is semi-supervised or even ​unsupervised learning. ​And another challenge is how to detect the copy behaviors of the false values. ​The evaluation is another issue. ​Most of the evaluation is based on the data distribution, and the trade-offs derided substantially ​from the norm-as-run answers. ​How do you identify the misinformation? ​The goal is to detect false, inaccurate, or misleading information from the data source. 

​There are several potential solutions. ​The first is to explore the mutual enhancement between the source trustworthiness and claim ​reliability. ​So basically, it is a similar idea from the truth discovery. ​And then another potential solution is to use the methods to distinguish misinformation ​with additional measures. ​For example, you build up information literacy and media literacy through education. ​Use common knowledge and open-mindedness, and you develop critical thinking. ​So you have to use the additional measures for this identified misinformation. 

​Finally, you determine the misinformation based on the individual's mental model and ​worldview beliefs, because some may believe in some sense and trade that the same information ​may be traded as misinformation in the other's belief. ​And you also need to consider the repetition of misinformation. ​There is a time lag or relative coherency between misinformation and corrective information.
