​Okay, so mining the rich data type, we will start with mining the text data and then mining ​the spatial temporal data and the mining graph and the networks. ​Mining the text data is very important because over 80% of data is an unstructured format ​such as news and images. ​So our goal is to derive high quality information such as structures, patterns, and summaries ​from unstructured text data. ​So the process is try to mine structures from the text, then derive the pattern within the ​structured data, then we evaluate and interpret the output. ​The main challenge for mining text data is how to present text primitives. ​For example, the words, the sentence, and the document, and how to learn effective representation ​from unstructured data. ​Now, mining text data will have the following major tasks. 

​The first is to extract the information. ​So information extraction is to automatically extract the structured information from unstructured ​or semi-structured documents. ​And the second task is taxonomy construction. ​Taxonomy construction is to construct different multi-faceted taxonomies based on different ​corporeal applications. ​And then another major task is to do the text clustering. ​What you want to do is to group unlabeled texts with similar contextual patterns. ​Then we also need to do the text classification. 

​So we want to analyze open-ended texts and assign them a set of predefined topics or categories. ​So for example, we want to assign the topic or categories to a website, or to emails, ​or to any short message, or any conversation. ​And then another task is text summarization. ​Text summarization is to create a subset of text that represents the most important information ​from a single or multiple pieces of text. ​The technologies used in mining text data include the symbol-based representation, ​where you use one-hop vectors for words and bag-of-words models for documents. ​Using this approach will have a high-dimensionality and data-subversive problem. ​The second approach is used to distributed representation, ​where you will create a low-dimensional real-valued dense vector with large amounts of unlabeled data ​using deep neural networks, ​where you create a word embedding in which words similar in meaning are expected to be closer in the embedded space. 

​We can also use pre-trained language models, ​where you use large-scale data and more computer resources to generate contextualized embeddings. ​And one of popular techniques called the word-to-vec. ​The idea is that the words that share common contexts are embedded in close proximity. ​For example, Sweden can be embedded close to Norway and Finland. ​You can use CBOW, which predicts the current words from the surrounding context words, ​or you use SCAPE-GRAM, where you use the current word to predict the surrounding word. ​There are other approaches such as GLOBAL, ​by combining the global matrix vectorization and a local context window method. ​And JOST is another method, ​where you try to learn the word embeddings in a hybrid space to model the hierarchical structure. 

​Of course, you can also use pre-trained language models such as ELMo and BUR.
