​The next trend in current data mining methodology and systems is data augmentation. ​Why do we need data augmentation? ​For a high-performing data mining model, we often require a great amount of enabled data samples for training. ​However, for many domains, we might only provide a limited number of enabled data. ​Training a data mining model with scarce training data could lead to an overfitting problem. ​So, the basic data augmentation methods include free-ping, rotation, equalization, and so on. ​Some advanced methods include augmentation policy learning by combining multiple basic augmentation methods, ​or GANs-based methods by training a GAN model to generate new data, ​or use the adversarial training by mixing tricky perturbed samples into a training sample to provide data augmentation.
