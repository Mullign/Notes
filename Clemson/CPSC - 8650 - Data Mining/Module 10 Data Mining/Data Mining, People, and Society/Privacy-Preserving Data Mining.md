​Now we study the privacy preserving the data mining. ​Private leakage often happens between the users and the owners. ​For example, owners may re-identify users based on anonymous reviews on the products. ​To protect the users' privacy, you should anonymize the data. ​Back in 1998, a k-anonymity algorithm was proposed. ​The idea is to generalize the data so that it is identical to at least k minus one other record on the identifying attribute. ​In 2006, another approach was proposed called differential privacy. 

​The idea is to describe patterns of groups without sharing the individual information. ​They define the global sensitivity score as a function r, f, and a pair of neighboring data sets. ​So the global sensitivity f is the maximum difference between function values of f, d1, and f, d2, where d1 and d2 are neighboring data sets. ​The privacy also leaks between the data owners. ​For example, multiple companies collaboratively conduct data mining but refuse to share user information. ​For that, we have the solution like federated learning and analytics. ​The idea of federated learning is to run local computation over each data owner's devices and aggregate results without leaking detailed information from individual data owners. 

​For example, we run the federated k-means algorithm. ​There are two kinds of federated learning. One is called horizontal federated learning. Another is vertical federated learning. ​For the horizontal federated learning, the data owned by each data owner follows the same schema. ​While for vertical federated learning, different data owners may have the data on only some attributes or objects. ​The reason we call it horizontal federated learning is because you can view that the data on each data owner's devices are the entire row of the data. 

​So they're only partial of the data. That's horizontal, row by row. ​The vertical is like it is possible they have all the data, but all partial data, but they also only contain the attributes, certain attributes. ​For example, in some departments or some institutes, different departments may be interested in the different attributes in their data mining process.
