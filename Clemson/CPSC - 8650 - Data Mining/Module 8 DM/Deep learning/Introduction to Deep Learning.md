​In this module, we are going to study deep learning. ​First, we will study what is deep learning and why do we need deep learning. ​Then, we will discuss the challenges in training the deep learning models ​and discuss how to improve the training for deep learning models. ​And we will study two kinds of deep learning networks. ​One is called convolutional neural networks and another is recurrent neural networks. ​Then, we summarize what we learned in this module. ​Deep learning has been successful in the past 20 years ​and it was named by the MIT Technology Review as the 10 breakthrough technologies in 2013. 

​So, what is deep learning? ​Deep learning refers to training deep neural networks with many layers. ​Basically, it is deep. Deep means many layers. ​It also has more neurons and more layers. ​Because with more neurons and more layers, a fully connected network may not be efficient. ​So, we need more complex ways to connect the layers. 

​Deep learning has some major advantages that make it popular. ​First, of course, it has a tremendous improved performance in many tasks. ​For example, in the image recognition, in natural language processing, in AI gaming training, and etc. ​Also, it requires no feature engineering or at least the next feature in engineering. ​So, it makes end-to-end models possible. ​With deep learning, you don't need to extract features or pre-process data. ​You can apply the raw data and then take it into the model and output the learning results. 

​Several factors lead to the deep learning success. ​First, we have a very large dataset now. ​And there are tremendous data available nowadays. ​And secondly, there is a massive amount of computational power with the GPU accelerations. ​So, of course, with the data and the hardware computational power, we still need architecture. ​So, we have, in past years, developed some advanced neural network structures. ​And also developed techniques to improve the training for those networks. 

​So, for example, we have developed the CNN for image recognition, for RNN for natural language processing. ​And then we developed the tricks for dropout, renal activation, and residual connection to improve the network performance. ​And there are several typical deep learning architectures. ​For the traditional multidimensional data, we can use the feedforward network we already studied. ​And then we studied how to train this network, how to use the back-up propagation net algorithm to learn the weights. ​And then for the great data such as imaging, we can apply CNN, which is a convolutional neural network. ​And we will study that.
