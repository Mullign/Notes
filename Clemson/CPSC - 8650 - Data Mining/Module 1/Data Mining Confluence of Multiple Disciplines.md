So actually, in the data mining field, you need a lot of knowledge, and it's involved with multiple disciplines, it's involved with statistics, you need pattern recognition, you need visualization, you need algorithms, you need high-performance computing, then it is also related to the applications, and social science, database technologies, natural language processing. So it is a conference of multi-disciplines. Why we call it a conference of multi-disciplines? Because it has a tremendous amount of data. So your algorithms must be able to scale to handle big data. To handle the big data, you need a storage, right? You need computer knowledge. You store a lot of data. You need to process this data. So you need a database, you need to handle this data. And then also, the data is a high dimension. 

For example, a microarray may have tens of thousands of dimensions, and some network has so many nodes. So to process such high-dimensional data, you need a lot of computation power. So that means you need a high-performance computing, right? And then data sometimes is highly complex, such as data stream or sensor data, and time series data, temporal data, sequential data, sequence data, okay? And then some data is a structure, and some data is a semi-structure, like graph data, social or information networks. And also spatial, temporal, multimedia, text, and web data. So the high-complexity data requires different fields or disciplines to handle them, okay? And of course, with the current technology involved, and then we may have new and sophisticated applications, such as automatic driving car.
