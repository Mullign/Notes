![[what is data mining slides.pdf]]Currently, we live in a world where vast amounts of data are generated constantly and rapidly. Data mining is the process of discovering interest patterns, models, and other kinds knowledge in large datasets. Actually, data mining is a misnomer. You should call it knowledge mining from data or mining knowledge from data. So the most accurate terms can be knowledge mining from data, knowledge discovery from data. There are some other terms used such as pattern discovery, knowledge extraction, data analytics, information harvesting. So we are not actually mining the data, we are mining the knowledge. 

Data mining is a young, dynamic, and promising field. Data mining extends a large collection of data into knowledge. For example, Google's FluTrends found a close relationship between the number of people who search for flu-related information and the number of people who have flu symptoms. So it can estimate flu activity up to two weeks faster than the traditional systems. So data mining is an essential step in the knowledge discovery. So the knowledge discovery process includes four steps. The first step is to prepare the data. 

To prepare the data, we need to clean the data and integrate the data. And then probably we want to transform the data and then we want to select the data for data mining. After we prepare the data, we will apply the data mining algorithms and then generate the patterns and knowledge. Then our next step is to evaluate the knowledge, make sure the patterns and knowledge are interesting. Then finally, we present the knowledge to the user.
